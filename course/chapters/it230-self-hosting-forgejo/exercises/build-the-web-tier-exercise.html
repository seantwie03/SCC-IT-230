Exercise

Build the Web Tier Exercise

Task

Make httpd on servera Forgejo's web tier: a reverse proxy that answers on port 80 and forwards each request to Forgejo, whose own port, 3000, stays closed to other hosts. Give workstation a name for the site, git.lab.example.com, and use sealert to find the one SELinux setting the proxy needs. The next exercise, Operate Forgejo, backs up what the last three built and reads httpd's log, so leave the lab as this exercise ends.

Hosts
workstation and servera
Prerequisite
Build the App Tier

  1. Name servera git.lab.example.com on workstation

    Open a terminal on workstation as student. workstation finds servera through DNS; /etc/hosts adds a name of your own: 

    sudo vim /etc/hosts

    Press G to go to the last line and o to open a line below it, then type: 

    172.25.250.10 git.lab.example.com

    Press Esc, then type :wq and press Enter. The name now resolves to servera, where nothing answers on port 80 yet: 

    curl git.lab.example.com
    curl: (7) Failed to connect to git.lab.example.com port 80 after 0 ms: Could not connect to server

  2. Install httpd on servera and reverse proxy it to Forgejo 

    ssh servera
sudo dnf install -y httpd

    If SSH asks whether to trust servera's host key, answer yes. Forgejo's documentation for Apache gives three lines for a reverse proxy. Put them in a file of their own in /etc/httpd/conf.d/: 

    sudo vim /etc/httpd/conf.d/forgejo.conf

    Press i and type:

    ProxyPreserveHost On
AllowEncodedSlashes NoDecode
ProxyPass / http://127.0.0.1:3000/ nocanon

    Press Esc, then type :wq and press Enter. The lines, in order:

    • ProxyPreserveHost On passes on the name the browser asked for, git.lab.example.com.
    • AllowEncodedSlashes NoDecode accepts encoded slashes in paths and leaves them encoded.
    • ProxyPass forwards every path on this site, /, to Forgejo at http://127.0.0.1:3000/, on servera's own loopback address. nocanon passes each path on as it came, so encoded characters reach Forgejo intact.

  3. Start httpd and open the firewall for http

    sudo systemctl enable --now httpd
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --reload
    Created symlink '/etc/systemd/system/multi-user.target.wants/httpd.service' → '/usr/lib/systemd/system/httpd.service'.
success
success

    Only http opens: Forgejo's port 3000 stays closed to other hosts, so every request reaches Forgejo through httpd. Test the proxy on servera: 

    curl -s localhost | grep '<title>'
    <title>503 Service Unavailable</title>

    503 means httpd is answering, but it cannot reach Forgejo.

  4. Use sealert to figure out why the reverse proxy fails 

    sudo dnf install -y setroubleshoot-server

    On the SCC lab, setroubleshoot-server is already installed, and dnf has nothing to do. Read the audit log through sealert: 

    sudo sealert -a /var/log/audit/audit.log | less

    Your log may hold older, unrelated alerts. Type /port 3000 and press Enter to find this one: 

    SELinux is preventing /usr/sbin/httpd from name_connect access on the tcp_socket port 3000.

*****  Plugin catchall_boolean (89.3 confidence) suggests   ******************

If you want to allow httpd to can network connect
Then you must tell SELinux about this by enabling the 'httpd_can_network_connect' boolean.

Do
setsebool -P httpd_can_network_connect 1

    httpd tried to connect to Forgejo on port 3000, and SELinux refused. sealert names the boolean that allows it. Press q to leave less.

  5. Let httpd connect to Forgejo and test from workstation 

    sudo setsebool -P httpd_can_network_connect on
curl -s localhost | grep '<title>'
    	<title>Forgejo: Beyond coding. We forge.</title>

    -P keeps the boolean across reboots, and setsebool takes several seconds to write it. Return to workstation and reach the site by its name: 

    exit
curl -s git.lab.example.com | grep '<title>'
    	<title>Forgejo: Beyond coding. We forge.</title>

    Finally, open http://git.lab.example.com in Firefox on workstation, and log in as student with the password student, the admin from Build the App Tier. Leave the lab as it is: Operate Forgejo backs it up.
