Exercise

Manage Container Images Exercise

Task

You need a web server image for servera. Find out where Podman looks for images, search for an Apache HTTP Server (httpd) image, download one from Red Hat and one from Docker Hub, compare them, and remove the one you will not use.

Host
servera
Prerequisite
Run Your First Container

  1. Find the registries Podman searches

    Connect to servera, then look for the list of registries in Podman's system-wide registry configuration. 

    ssh servera
grep ^unqualified /etc/containers/registries.conf
    unqualified-search-registries = ["registry.access.redhat.com", "registry.redhat.io", "docker.io"]

    When an image name does not say which registry it comes from, Podman searches these three, in this order. podman info lists the same three under registries:.

  2. Search the registries for an httpd-24 image

    podman search httpd-24

    The list runs to about 30 lines. Red Hat's images come first, among them registry.redhat.io/ubi10/httpd-24; the rest are from docker.io, including Docker Hub's official docker.io/library/httpd.

    Why no registry.access.redhat.com registry.access.redhat.com does not answer searches, so its images appear only under registry.redhat.io. Red Hat's Universal Base Images (UBI) are on both, and registry.access.redhat.com serves them without a login. To browse Red Hat's images instead, use catalog.redhat.com.

  3. Pull ubi10/httpd-24 from registry.access.redhat.com and httpd from docker.io 

    podman pull registry.access.redhat.com/ubi10/httpd-24
podman pull docker.io/library/httpd

    Each pull prints progress bars for the image's layers and ends with the new image's full ID. The Red Hat image is about 290 MB, Docker Hub's about 120 MB.

  4. List the local images

    podman images
    REPOSITORY                                 TAG         IMAGE ID      CREATED     SIZE
registry.access.redhat.com/ubi10/ubi       latest      747428888698  2 days ago  220 MB
docker.io/library/httpd                    latest      caeb353ae229  3 days ago  121 MB
registry.access.redhat.com/ubi10/httpd-24  latest      c0cfc32ec96b  9 days ago  286 MB

    ubi10/ubi is still here from the Run Your First Container exercise. Your image IDs, ages, and sizes will differ: the latest tag moves to each new release of an image.

  5. Find the ports each httpd image exposes

    podman image inspect --format '{{.Config.ExposedPorts}}' ubi10/httpd-24
podman image inspect --format '{{.Config.ExposedPorts}}' docker.io/library/httpd
    map[8080/tcp:{} 8443/tcp:{}]
map[80/tcp:{}]

    Red Hat's image runs httpd on port 8080, and 8443 for HTTPS; Docker Hub's runs it on port 80. Both are web servers, but you will need the right port number to reach each one. A local image can be named by its repository alone, such as ubi10/httpd-24.

  6. Remove the docker.io image

    podman rmi docker.io/library/httpd
podman images

    podman rmi prints Untagged: docker.io/library/httpd:latest and the deleted image's ID, and the list no longer shows it.

    Keep ubi10/httpd-24 and ubi10/ubi: the Manage a Container exercise runs a web server from ubi10/httpd-24.
