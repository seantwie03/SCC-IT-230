# Accessing RHA Lab

## Launch Workstation Console

- Lab Environment tab
- Create
- Open Console on workstation
- Show the application menu
- Show increasing resolution
- Launch a terminal
  - Maximize the window
  - Increase the font size (Ctrl+Shift+Plus)
  - Explain console, terminal, shell
  - Reopen the terminal
  - Show multiple tabs

## SSH to servera

- From the workstation terminal
  - `whoami`
  - `hostname`
  - `ssh student@servera`
    - `whoami`
    - `hostname`
    - `exit`
  - `whoami`
  - `hostname`
  - `ssh root@servera`
    - `whoami`
    - `hostname`
    - `exit`
  - `whoami`
  - `ssh servera`
    - Notice the same user is assumed

## Copy/paste text

- Go to the Course tab
- Copy any text
- Go to the Lab Environment tab
- Enable Host Paste
- Paste with Ctrl+V
- Do the same with `Open Text Dialogue`
