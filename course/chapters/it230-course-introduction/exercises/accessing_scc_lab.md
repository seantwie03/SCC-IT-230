# Accessing SCC Lab

## Start the workstation VM

- Open VirtualBox
- Double-click workstation
- Show the application menu
- Launch a terminal

## SSH to servera

- In VirtualBox, start servera in headless mode
- From the workstation terminal
  - `ssh servera`
    - `whoami`
    - `hostname`
    - `exit`

## SSH from Windows Terminal on Windows

- Open Windows Terminal
- `ssh servera`
  - `exit`
- `ssh servera-root`
  - `exit`

## Copy/paste text

- Copy any text
- Ctrl+Shift+V in Windows Terminal
