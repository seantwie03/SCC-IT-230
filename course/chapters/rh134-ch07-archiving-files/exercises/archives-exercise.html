Creating and Extracting Archives Exercise

Overview

An archive is one file that holds many files, along with the directory structure, ownership, permissions, and timestamps that a plain copy can lose.

In this hands-on exercise you will bundle the entire /etc directory into a single uncompressed archive, read its contents without unpacking it, extract the whole archive into a directory of its own, and then extract just one file from it.

Target host
servera
Run as
root

  1. Connect to the lab host and become root

    Reading every file under /etc requires administrative privileges. 

    ssh student@servera
sudo -i

  2. Create an uncompressed archive

    -c creates, -v lists each member as it is added, and -f names the archive file. 

    tar -cvf /tmp/etc-backup.tar /etc
    Read the first line of output tar reports that it is removing the leading slash from the member names. That is deliberate: it means extracting this archive somewhere else cannot overwrite the real /etc.

  3. Check the size of the archive

    -h prints the size in human-readable units. 

    ls -lh /tmp/etc-backup.tar

  4. Read the contents without unpacking

    -t lists the members. Notice that every path is stored without its leading slash. 

    tar -tf /tmp/etc-backup.tar | head -n 20

  5. Extract the archive into an empty directory

    tar unpacks into the current working directory, so change into a directory of its own first. 

    mkdir -p /tmp/etc-extract
cd /tmp/etc-extract
tar -xf /tmp/etc-backup.tar
ls

  6. Confirm the extracted tree

    Compare one extracted file against the original. diff printing nothing means the two files are identical. 

    ls -l /tmp/etc-extract/etc | head -n 10
diff /tmp/etc-extract/etc/hosts /etc/hosts

  7. Extract a single file

    Name the member you want, exactly as -t printed it — etc/hosts, not /etc/hosts. 

    mkdir -p /tmp/etc-one
cd /tmp/etc-one
tar -xf /tmp/etc-backup.tar etc/hosts
ls -R /tmp/etc-one
    Keep the archive The compression exercise continues from the /tmp/etc-backup.tar you just built, so leave it in place for now.
