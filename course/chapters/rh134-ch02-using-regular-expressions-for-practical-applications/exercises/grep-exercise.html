Searching Log Files with grep Exercise

Overview

In this hands-on exercise you will search the system log with grep. You will match a plain string, print the lines surrounding a match, remove lines you do not care about, search for two patterns at once, and make a search ignore capitalization.

Every command reads /var/log/messages, which is readable only by root, so each one is run with sudo.

Target host
servera

  1. Connect to the lab host

    From your lab workstation, connect to servera. 

    ssh student@servera

  2. Find every line that mentions the SSH service

    The simplest regular expression is an exact string. grep prints every line of the file that contains it. 

    sudo grep 'sshd' /var/log/messages

  3. Read the neighborhood around a match

    A matching line is rarely the whole story. -C3 prints three lines on each side of the match. 

    sudo grep -C3 'Startup finished' /var/log/messages

  4. Read forward and backward from a match

    Use -A when you have an event and want to know what happened next. 

    sudo grep -A2 'Reached target' /var/log/messages

    Use -B when you have a symptom and want to know what led to it. 

    sudo grep -B2 'Startup finished' /var/log/messages
    Counting lines -C3, -A3, and -B3 are short forms of --context=3, --after-context=3, and --before-context=3.

  5. Remove the noise with an inverted match

    Start with a search that returns far too much.

    sudo grep 'systemd' /var/log/messages

    Pipe it into a second grep with -v, which prints every line that does not match. 

    sudo grep 'systemd' /var/log/messages | grep -v 'systemd --user'

  6. Search for two services in one command

    Give -e once per pattern. A line matching either pattern is printed. 

    sudo grep -e 'sshd' -e 'chronyd' /var/log/messages

  7. Ignore capitalization

    Run the search twice and compare the results. Without -i, the pattern misses every line that spells the word with a capital letter. 

    sudo grep 'finished' /var/log/messages
sudo grep -i 'finished' /var/log/messages
    Key idea Options change how the pattern is applied. The pattern itself did not change between those two commands.
